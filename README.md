
# 🏝️ جزيرة المعرفة

موسوعة عربية تجمع التاريخ والثقافة والتراث والجغرافيا والمعارف الإنسانية.

## أقسام الموسوعة

- التاريخ والحضارات
- الثقافة والتراث
- الجغرافيا والبلدان
- شخصيات ومعارف

## رؤية المشروع

تقديم المعرفة التاريخية والثقافية بأسلوب عربي واضح،
وبناء موسوعة معرفية قابلة للتطوير والتوسع.

## حالة المشروع

نسخة أولية قيد التطوير.
